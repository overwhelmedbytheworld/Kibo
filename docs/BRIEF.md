# Kibo
A keyboard-first macOS utility for clipboard history, prompt management, and universal text insertion.

## Replaces
Manually copying and pasting prompts, re-typing snippets, and most importantly finding emojis from god knows where. Also, a basic clipboard history/manager.

## Main jobs
1. Save and reuse text snippets and AI prompts with trigger aliases.
2. Search and insert any saved or copied content via a floating panel.
3. Remember clipboard history and make it searchable.

## Shape
Menu bar extra + floating search panel + management window, macOS 15 or later.
Everything is local, works offline, without any account.

## System hooks
Global shortcut (⌘⇧K), menu bar icon, clipboard monitoring, trigger detection via event tap.

## Look
Native with system accent colour. Own floating panel design. No custom design kit.
